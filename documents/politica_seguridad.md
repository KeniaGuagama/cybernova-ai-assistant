# Política de Seguridad de la Información
## CyberNova Solutions

## Objetivo

Esta política establece las normas para proteger la información, sistemas tecnológicos y recursos digitales de CyberNova Solutions.

## Protección de contraseñas

Todos los colaboradores deben:

- Utilizar contraseñas personales.
- No compartir credenciales.
- Utilizar contraseñas con mínimo 12 caracteres.
- Activar autenticación multifactor cuando esté disponible.

Está prohibido:

- Compartir contraseñas.
- Utilizar contraseñas de otros usuarios.
- Guardar contraseñas en documentos no protegidos.

## Uso de equipos corporativos

Los dispositivos empresariales deben:

- Mantener actualizaciones de seguridad.
- Tener antivirus activo.
- Bloquear pantalla cuando no estén siendo utilizados.

## Protección de información

Los colaboradores deben proteger:

- Datos de clientes.
- Información financiera.
- Documentos internos.

La información confidencial no debe enviarse mediante canales no autorizados.

# Conceptos Básicos de Ciberseguridad

## ¿Qué es la ciberseguridad?

La ciberseguridad es el conjunto de prácticas y tecnologías utilizadas para proteger sistemas, redes y datos frente a amenazas digitales.

## ¿Qué es phishing?

El phishing es un ataque en el que un delincuente intenta engañar al usuario mediante correos electrónicos, mensajes o sitios web falsos para obtener información confidencial.

## ¿Qué es malware?

El malware es un software malicioso diseñado para dañar sistemas, robar información o interrumpir el funcionamiento de los equipos.

## ¿Qué es ransomware?

El ransomware es un tipo de malware que cifra los archivos de un dispositivo y solicita un pago para recuperarlos.

## ¿Qué es un firewall?

Un firewall es un sistema de seguridad que controla el tráfico de red y bloquea accesos no autorizados.

## ¿Qué es un antivirus?

Un antivirus es un software diseñado para detectar, bloquear y eliminar programas maliciosos.

## ¿Qué es la autenticación multifactor?

La autenticación multifactor (MFA) requiere dos o más métodos de verificación para acceder a una cuenta y mejorar la seguridad.

## ¿Qué es la ingeniería social?

La ingeniería social consiste en manipular a las personas para obtener información confidencial o acceso a sistemas.

## ¿Qué es un ataque DDoS?

Un ataque DDoS busca saturar un servidor o servicio con un gran volumen de solicitudes para impedir su funcionamiento normal.

## ¿Qué es una VPN?

Una VPN crea una conexión cifrada entre el usuario y la red corporativa para proteger la información transmitida.

## ¿Qué es el cifrado?

El cifrado es un proceso que convierte la información en un formato ilegible para proteger su confidencialidad.
